# Library Management System

A Library Management System developed using Node.js, Express and PostgreSQL.

## Project Features

- Add, edit, delete and search books
- Register and edit members
- Issue books
- Return books
- Renew books
- Automatic fine calculation
- Dashboard
- REST APIs

## User Roles

### Admin
- Manage librarians
- View reports

### Librarian
- Manage books
- Manage members
- Issue books
- Return books

### Member
- Search books
- View own borrowing history
